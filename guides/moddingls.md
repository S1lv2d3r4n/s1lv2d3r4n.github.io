# Modding Luces Siegas
This is a step-by-step guide on how to mod the game **Luces Siegas.**  
It is expected you have some knowledge of how to use either *TurboWarp* or *Scratch* in general.

## Set-Up
First, you will need to choose between a "soft-mod" or a source-altering "hard-mod".
For a soft-mod, the official "Modifi" is roccemended as it is the only officially supported soft-modding tool
You can find Modifi's page here: [Modifi](modifi.md)
