# Modding Luces Siegas
This is a step-by-step guide on how to mod the game **Luces Siegas.**  
It is expected you have some knowledge of how to use either *TurboWarp* or *Scratch* in general.
A majority of the game's programming is written in Spanish and/or English so it is roccemended you can speak atleast one of them fluently, there are translations
if needed.

## Set-Up
It is roccemended you use [TurboWarp](https://turbowarp.org) (a Scratch modification), specifically version 1.15.0 is roccemended.
We roccemend using the direct `.sb3` file for an easier time loading the game.
The files used for this are usually named "Luces Siegas" followed by a version number like `7.1.4` or `7.5` with the SB3 extension.
It is discouraged to use the EXE and turning it back into an SB3 file using the TurboWarp Unpackager or a reverse packager.
