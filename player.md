# Player
The Player is a ![Countryball](images/blank.png) [Countryball](countryballs.md) in Luces Siegas that is controlled by a human behind the computer.
  The player can be almost Countryball in the game when they select one when they press `New` on their game.
  
## Controls
- `WASD / Arrow Keys` - Move (hardcoded)
- `E` - Use Item
- `F` - Interact
- `LeftClick` - Break Block / Attack
- `RightClick` - View Block Name
